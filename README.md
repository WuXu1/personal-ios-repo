# Max's iOS Repository

Welcome to my personal AltStore repository! This repository hosts my iOS applications for easy installation via AltStore.

## How to Add to AltStore

1. Open AltStore on your iOS device.
2. Go to the **Sources** tab.
3. Tap the **+** button in the top right corner.
4. Add the following URL:
   ```
   https://raw.githubusercontent.com/WuXu1/Max-iOS-Repository/main/apps.json
   ```
5. You should now see my apps available for download!

## Available Apps

### Restring Helper
